# Internship Support Chatbot

## Project Overview

This project is an AI-based chatbot designed to answer common questions related to an internship program.

The chatbot uses Natural Language Processing (NLP) with Hugging Face Transformers to identify the most relevant FAQ and provide an appropriate response.

## Objective

To provide automated responses to common internship-related questions and reduce the need for manual support.

## Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Jupyter Notebook

## NLP Model

The project uses the Hugging Face `facebook/bart-large-mnli` model for zero-shot classification.

## Features

- Answers common internship questions
- Matches user questions with relevant FAQs
- Provides automated responses
- Handles questions about projects, mentors, tasks, working hours, and certificates
